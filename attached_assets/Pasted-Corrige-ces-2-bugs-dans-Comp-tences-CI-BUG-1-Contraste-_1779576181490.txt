Corrige ces 2 bugs dans Compétences CI :

## BUG 1 — Contraste insuffisant sur la card "Créateur"

La card "Créateur" dans la page À propos a un fond 
beige/crème clair (#FAF5EB ou similaire) avec du texte 
gris clair, ce qui rend la lecture très difficile.

Corrige le contraste ainsi :

/* Trouve la card Créateur et applique ces styles */

/* Option A — Garde le fond clair mais assombris le texte */
.card-createur {
  background-color: #FEF3E2;
}

.card-createur .titre {
  color: #92400E; /* orange foncé, bien lisible */
  font-weight: 700;
}

.card-createur .texte {
  color: #1F2937; /* gris très foncé, presque noir */
  font-weight: 500;
}

/* Option B — Passe la card en dark comme le reste de l'app */
.card-createur {
  background-color: #1C2333;
  border: 1px solid #374151;
}

.card-createur .titre {
  color: #F97316; /* orange accent */
  font-weight: 700;
}

.card-createur .texte {
  color: #F9FAFB; /* blanc cassé */
  font-weight: 400;
}

Applique l'Option B pour rester cohérent avec 
le design sombre de l'app.

En JSX, la card doit ressembler à :
<div className="bg-gray-800 border border-gray-700 
  rounded-2xl p-4">
  <div className="flex items-center gap-2 mb-3">
    <span className="text-orange-500 text-xl">🧡</span>
    <p className="text-orange-500 font-bold text-base">
      Créateur
    </p>
  </div>
  <p className="text-white font-medium text-base">
    Application créée par Yao Brou Joris Aymard.
  </p>
</div>


## BUG 2 — Page Contact → Erreur 404 "Page Not Found"

Quand l'utilisateur clique sur "Contact" dans le menu 
latéral, il obtient une erreur 404 car la route 
n'existe pas dans le router.

### Correction 1 — Ajoute la route manquante

Dans ton fichier de routing principal 
(App.jsx ou Router.jsx), ajoute :

import ContactPage from './pages/ContactPage';
// ou selon ton arborescence :
import ContactPage from './components/Contact';

// Dans les routes :
<Route path="/contact" element={<ContactPage />} />

### Correction 3 — Vérifie le lien dans le menu

Dans le menu latéral, assure-toi que le lien 
Contact pointe bien vers la bonne route :

// Mauvais :
<Link to="contact">Contact</Link>

// Correct :
<Link to="/contact">Contact</Link>

// Vérifie aussi que onClick ferme le menu 
// avant de naviguer :
<Link 
  to="/contact" 
  onClick={() => setMenuOpen(false)}
>
  Contact
</Link>
