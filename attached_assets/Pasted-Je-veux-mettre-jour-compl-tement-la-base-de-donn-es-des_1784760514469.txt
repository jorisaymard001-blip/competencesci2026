## ÉTAPE 3 — Retire ces concours sans source fiable 
## confirmée

Pour les 2 concours suivants, aucune source officielle 
fiable n'a été trouvée organisant un concours grand public 
sous ce nom exact en Côte d'Ivoire. RETIRE-LES complètement 
de la base de données :

### Concours d'entrée à l'ENSEA
Raison : L'ENSEA (École Nationale Supérieure de Statistique 
et d'Économie Appliquée) recrute principalement ses élèves-
ingénieurs via des voies spécifiques (concours communs 
sous-régionaux, admission sur dossier), pas via un grand 
concours public national grand public comme les autres 
concours listés dans l'application. Aucune page 
d'inscription publique équivalente et confirmée n'a été 
trouvée. À supprimer de la base de données.

### Recrutement de chercheurs scientifiques au CNRST
Raison : Aucune trace d'un concours de recrutement grand 
public organisé par le CNRST (Centre National de Recherche 
Scientifique et Technologique) n'a été trouvée dans les 
sources disponibles. Ce type de recrutement, si réel, 
passerait probablement par appel à candidatures spécifique 
et non par un concours classique. À supprimer de la base 
de données.

Vérifie qu'aucune image, lien, carte ou référence à ces 
2 concours ne reste nulle part dans le code après 
suppression : composants de liste, pages détail, favoris, 
notifications, recherche. Fais une recherche globale dans 
le projet avec les termes "ENSEA" et "CNRST" pour confirmer 
qu'il ne reste aucune trace orpheline.

## ÉTAPE 4 — Corrige le format d'affichage des cards 
## concours si nécessaire

Vérifie que chaque card de concours dans la liste affiche 
proprement, sans débordement ni troncature :

<div className="bg-gray-800 border border-gray-700 
  rounded-2xl p-4 mb-3">
  <div className="flex justify-between items-start mb-2">
    <span className="px-2.5 py-1 rounded-full text-xs 
      font-black bg-green-950 text-green-400">
      STATUT
    </span>
    <span className="bg-gray-700 text-gray-300 px-2.5 
      py-1 rounded-full text-xs font-medium">
      💼 X postes
    </span>
  </div>
  <h3 className="text-white font-bold text-base 
    leading-tight mt-2">
    {concours.nom}
  </h3>
  <p className="text-gray-400 text-sm mt-1 
    line-clamp-2">
    {concours.ministere}
  </p>
</div>

Le nom du ministère ne doit jamais être tronqué de façon 
illisible — utilise line-clamp-2 plutôt qu'une troncature 
sur une seule ligne si le texte est long.

## ÉTAPE 5 — Ajoute un système de gestion d'erreur pour 
## les liens externes

Quand l'utilisateur clique sur "Plus d'informations" ou un 
lien externe vers le site officiel d'un concours, ajoute une 
vérification basique pour éviter un lien mort silencieux :

<a 
  href={concours.urlInscription}
  target="_blank"
  rel="noopener noreferrer"
  onClick={(e) => {
    if (!concours.urlInscription) {
      e.preventDefault();
      alert('Le lien d\'inscription sera bientôt disponible.');
    }
  }}
  className="..."
>
  S'inscrire sur le site officiel →
</a>
