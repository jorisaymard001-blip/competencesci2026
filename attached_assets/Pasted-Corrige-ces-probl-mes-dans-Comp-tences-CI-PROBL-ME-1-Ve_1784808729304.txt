## PROBLÈME 1 — Version ordinateur : layout cassé

Sur grand écran (ordinateur), la sidebar gauche 
s'affiche en permanence et prend trop de place. 
Le contenu principal n'est pas bien mis en page 
(affichage en liste simple au lieu d'une mise en 
page desktop propre).

### Ce qui doit changer :

La sidebar gauche (menu avec Accueil, Écoles, 
Concours, Mes outils, etc.) ne doit PAS être 
visible par défaut quand on ouvre l'application 
sur ordinateur.

À la place, mets un bouton hamburger (☰) en haut 
à gauche comme sur mobile. Quand l'utilisateur 
clique dessus, le menu latéral s'ouvre en panneau 
glissant (drawer) par-dessus le contenu, exactement 
comme sur mobile.

Le contenu principal (accueil, écoles, concours, 
etc.) doit occuper TOUTE la largeur de l'écran 
sur ordinateur, sans sidebar fixe à gauche.

### Code à appliquer :

/* Cache la sidebar fixe sur tous les écrans */
.sidebar-desktop {
  display: none !important;
}

/* Le contenu principal prend toute la largeur */
main, .main-content {
  margin-left: 0 !important;
  width: 100% !important;
  max-width: 100% !important;
}

/* Affiche le bouton hamburger sur tous les écrans */
.hamburger-button {
  display: flex !important;
}

/* Le drawer (menu glissant) s'ouvre sur tous 
   les écrans de la même façon */
.drawer-overlay {
  display: block;
}

En React/JSX, assure-toi que :
- Le bouton hamburger ☰ est toujours visible 
  en haut à gauche quel que soit l'écran
- Le menu s'ouvre en drawer par-dessus le 
  contenu quand on clique sur ☰
- Le menu se ferme quand on clique en dehors
- Il n'y a AUCUNE sidebar fixe permanente 
  sur aucune taille d'écran

### Pour le contenu de la page d'accueil 
### sur grand écran :

Le contenu doit être centré et limité en largeur 
pour ne pas être trop étiré sur grand écran :

.page-content {
  max-width: 900px;
  margin: 0 auto;
  padding: 24px 32px;
}

Les cards "Explorer" (Annuaire des Écoles, 
Concours Publics, etc.) doivent s'afficher en 
grille 2 colonnes sur grand écran, pas en liste 
verticale :

.explorer-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}

@media (min-width: 1024px) {
  .explorer-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

Les stats (25 Écoles, Concours Ouverts, Villes) 
doivent être dans une ligne horizontale qui ne 
déborde pas, avec overflow hidden sur chaque card :

.stats-container {
  display: flex;
  gap: 12px;
  overflow-x: auto;
}

.stat-card {
  flex-shrink: 0;
  min-width: 140px;
  overflow: hidden;
}

.stat-card p, .stat-card span {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
