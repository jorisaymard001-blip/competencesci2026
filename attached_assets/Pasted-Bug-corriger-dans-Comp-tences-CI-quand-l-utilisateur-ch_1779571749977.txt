change la langue en anglais via i18next, les textes 
statiques se traduisent mais les données dynamiques 
venant de la base de données restent en français.

Exemples de données non traduites :
- Descriptions des écoles
- Noms des filières
- Frais de scolarité (labels)
- Conditions des concours
- Processus de sélection
- Documents requis
- Articles Conseils & Orientation

### ÉTAPE 2 — Configuration i18next (src/i18n/index.js)

import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import fr from './locales/fr.json';
import en from './locales/en.json';

i18n
  .use(initReactI18next)
  .init({
    resources: {
      fr: { translation: fr },
      en: { translation: en }
    },
    lng: localStorage.getItem('language') || 'fr',
    fallbackLng: 'fr',
    interpolation: {
      escapeValue: false
    }
  });

export default i18n;


### ÉTAPE 3 — Remplace TOUS les textes codés en dur

Dans CHAQUE composant, remplace les textes directs 
par les clés de traduction.

Exemple AVANT (mauvais) :
<h1>Écoles & Instituts</h1>
<p>40 établissements trouvés</p>
<span>Frais de scolarité</span>
<span>Frais d'inscription</span>
<p>Aucun avis pour cet établissement</p>

Exemple APRÈS (correct) :
import { useTranslation } from 'react-i18next';
const { t } = useTranslation();

<h1>{t('schools.title')}</h1>
<p>{count} {t('schools.found')}</p>
<span>{t('schools.tuition')}</span>
<span>{t('schools.registration')}</span>
<p>{t('common.noReview')}</p>

Fais ce remplacement dans ces fichiers :
- HomeScreen / HomePage
- SchoolsScreen / SchoolsList
- SchoolDetailScreen / SchoolDetail
- ContestsScreen / ContestsList  
- ContestDetailScreen / ContestDetail
- QuizScreen / TrouverMaVoie
- ProfileScreen
- MenuDrawer / Sidebar
- TipsScreen / ConseilsScreen
- NotificationService


### ÉTAPE 4 — Sauvegarde la langue choisie

Dans le composant qui gère le switch de langue :

import { useTranslation } from 'react-i18next';

const { i18n } = useTranslation();

const changeLanguage = (lang) => {
  i18n.changeLanguage(lang);
  localStorage.setItem('language', lang);
};

// Boutons de sélection :
<button onClick={() => changeLanguage('fr')}>🇫🇷 FR</button>
<button onClick={() => changeLanguage('en')}>🇬🇧 EN</button>
