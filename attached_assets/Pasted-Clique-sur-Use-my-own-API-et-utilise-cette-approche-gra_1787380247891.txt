Clique sur "Use my own API..." et utilise 
cette approche gratuite pour l'assistant IA.

N'utilise PAS l'intégration gérée Replit 
(payante). À la place, appelle directement 
l'API Anthropic depuis le backend Express 
déjà existant dans le projet.

## Implémentation via le backend Express

### Ajoute cette route dans server.js 
### ou index.js (le backend Express existant) :

const Anthropic = require('@anthropic-ai/sdk');

// Installe si pas déjà présent :
// npm install @anthropic-ai/sdk

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

app.post('/api/assistant', async (req, res) => {
  try {
    const { question, context } = req.body;

    if (!question) {
      return res.status(400).json({ 
        error: 'Question manquante' 
      });
    }

    const message = await anthropic.messages.create({
      model: 'claude-sonnet-4-6',
      max_tokens: 1024,
      system: `Tu es l'assistant officiel de 
        Compétences CI, une application 
        d'orientation académique et 
        professionnelle pour les étudiants 
        de Côte d'Ivoire.

        Données disponibles dans l'application :
        ${context ? JSON.stringify(context) : ''}

        Règles strictes :
        - Réponds UNIQUEMENT en français
        - Sois concis, pratique et bienveillant
        - Recommande des écoles et concours 
          spécifiques de la base de données 
          quand c'est pertinent
        - Maximum 3 paragraphes courts
        - Utilise des emojis pour rendre 
          la réponse agréable
        - Si tu ne connais pas la réponse, 
          dis-le honnêtement
        - Ne parle que d'orientation en 
          Côte d'Ivoire`,
      messages: [
        { role: 'user', content: question }
      ],
    });

    res.json({ 
      response: message.content[0].text 
    });

  } catch (error) {
    console.error('Assistant error:', error);
    res.status(500).json({ 
      error: 'Erreur assistant. Réessaie.',
      details: error.message
    });
  }
});


## Ajoute la clé dans Replit Secrets

Dans Replit, va dans l'onglet "Secrets" 
(icône 🔒 dans le panneau gauche) et 
ajoute ce secret :

Nom : ANTHROPIC_API_KEY
Valeur : (je vais te la fournir)

Pour obtenir une clé GRATUITE :
1. Va sur https://console.anthropic.com
2. Crée un compte gratuit
3. Va dans "API Keys" → "Create Key"
4. Copie la clé et mets-la dans 
   Replit Secrets

Le plan gratuit d'Anthropic offre 
suffisamment de crédits pour démarrer.


## Côté frontend — appelle le backend :

### Dans src/services/assistantService.js :

const API_URL = import.meta.env.VITE_API_URL 
  || 'http://localhost:3000';

export async function askAssistant(
  question, context
) {
  const response = await fetch(
    `${API_URL}/api/assistant`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${
          localStorage.getItem('token') || ''
        }`
      },
      body: JSON.stringify({ question, context })
    }
  );

  if (!response.ok) {
    throw new Error('Erreur de connexion');
  }

  const data = await response.json();
  return data.response;
}
