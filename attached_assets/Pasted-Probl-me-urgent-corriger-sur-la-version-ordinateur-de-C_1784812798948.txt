Problème urgent à corriger sur la version 
ordinateur de Compétences CI.

Actuellement sur ordinateur : la sidebar 
gauche (avec Accueil, Écoles, Concours, 
Mes outils, etc.) est toujours visible 
et occupe 280px à gauche, ce qui réduit 
l'espace du contenu principal.

## CE QUI DOIT CHANGER

### Comportement souhaité sur ordinateur :
- La sidebar gauche doit être CACHÉE 
  par défaut
- Seul un bouton ☰ (trois tirets) doit 
  être visible en haut à gauche
- Quand on clique sur ☰, la sidebar 
  s'ouvre par-dessus le contenu 
  (comme un drawer/panneau glissant)
- Quand on clique en dehors ou sur ✕, 
  la sidebar se referme
- Le contenu principal doit occuper 
  100% de la largeur de l'écran 
  en permanence

### Ce comportement doit être IDENTIQUE 
### sur tous les écrans (mobile, tablette, 
### ordinateur) — même système de drawer 
### partout, pas de sidebar fixe jamais

## CORRECTIONS À APPORTER

### 2. Le contenu de chaque page doit 
### occuper toute la largeur disponible

Dans chaque page (Accueil, Écoles, 
Concours, Profil, etc.), le wrapper 
principal doit être :

/* Sur mobile */
.page-wrapper {
  width: 100%;
  padding: 16px;
}

/* Sur grand écran */
@media (min-width: 1024px) {
  .page-wrapper {
    width: 100%;
    max-width: 1400px;
    margin: 0 auto;
    padding: 32px 48px;
  }
}

</div>
