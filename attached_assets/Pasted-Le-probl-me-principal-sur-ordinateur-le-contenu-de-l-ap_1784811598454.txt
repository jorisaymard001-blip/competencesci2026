Le problème principal sur ordinateur : le contenu 
de l'application est affiché dans un petit bloc 
centré qui ne remplit pas l'écran. Sur ordinateur, 
l'application doit détecter l'appareil et adapter 
son affichage pour occuper TOUT l'espace disponible.

## COMPORTEMENT ATTENDU PAR APPAREIL

### Sur téléphone (< 768px) :
- Affichage actuel conservé tel quel
- Bottom navigation visible en bas
- Bouton hamburger ☰ en haut à gauche
- Contenu pleine largeur

### Sur ordinateur (>= 1024px) :
- Sidebar fixe à gauche (280px) toujours visible
- Le contenu principal remplit TOUT le reste 
  de l'espace (calc(100% - 280px))
- Pas de bottom navigation
- Pas de bouton hamburger
- Grilles adaptées pour grand écran

### Sur tablette (768px - 1023px) :
- Bouton hamburger visible
- Drawer qui s'ouvre par-dessus
- Contenu pleine largeur


## ÉTAPE 1 — Détection de l'appareil

Crée src/hooks/useDevice.js :

import { useState, useEffect } from 'react';

export function useDevice() {
  const [device, setDevice] = useState({
    isMobile: window.innerWidth < 768,
    isTablet: window.innerWidth >= 768 && 
              window.innerWidth < 1024,
    isDesktop: window.innerWidth >= 1024,
  });

  useEffect(() => {
    const handleResize = () => {
      const width = window.innerWidth;
      setDevice({
        isMobile: width < 768,
        isTablet: width >= 768 && width < 1024,
        isDesktop: width >= 1024,
      });
    };

    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener(
      'resize', handleResize
    );
  }, []);

  return device;
}

      <div style={{ paddingBottom: '80px' }}>
        {children}
      </div>

      {/* Bottom navigation mobile */}
      <BottomNavigation />
    </div>
  );
}
