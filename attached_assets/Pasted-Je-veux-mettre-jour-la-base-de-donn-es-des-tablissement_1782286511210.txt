## ÉTAPE 2 — Corrige le format d'affichage des images

Actuellement, les images des écoles s'affichent comme des 
bannières rectangulaires géantes, mal cadrées, qui coupent 
le contenu (texte tronqué comme "UNIVERSIT" au lieu de 
"UNIVERSITÉ", logos déformés et zoomés au-delà du cadre 
visible). Corrige ce comportement partout où une image 
d'école est affichée (liste des écoles ET page détail).

### Applique ces règles strictes au composant d'affichage :

<div className="relative w-full h-40 overflow-hidden 
  rounded-t-2xl bg-gray-100 flex items-center 
  justify-center">
  <img 
    src={ecole.imageUrl} 
    alt={ecole.nom}
    className="w-full h-full object-contain p-4"
    onError={(e) => {
      e.target.onerror = null;
      e.target.src = '/images/establishments/placeholder.png';
    }}
  />
</div>

Règles obligatoires :
- Utilise "object-contain" et JAMAIS "object-cover" pour 
  les logos d'écoles, sinon le logo est zoomé et coupé sur 
  les bords
- Ajoute un padding (p-4) autour de l'image pour qu'elle 
  ne touche jamais les bords du cadre
- Hauteur fixe de la zone image : h-40 (160px) maximum, 
  jamais plus, sur la liste comme sur le détail
- Fond neutre gris clair (bg-gray-100) derrière le logo 
  pour gérer les logos à fond transparent
- Le logo doit toujours être entièrement visible et centré, 
  jamais coupé ni débordant du cadre

Si l'image source actuelle est une bannière web large 
(comme celle d'INP-HB ou Université Alassane Ouattara) 
plutôt qu'un logo carré/rond compact :
- Recadre-la pour ne garder que le logo/emblème central, 
  sans le bandeau de texte qui dépasse
- Si aucun logo propre n'est trouvable pour un établissement, 
  utilise un placeholder neutre avec une icône 🎓 plutôt 
  qu'une bannière mal cadrée

## ÉTAPE 6 — Méthode technique pour le stockage des images

- Télécharge les images dans /public/images/establishments/ 
  plutôt que de faire un lien direct (hotlink) vers les 
  sites externes, pour éviter les problèmes de chargement
- Nomme les fichiers de façon cohérente : ufhb.png, 
  inphb.png, ensea.png, ena.png, iua.png, ucao.png, etc.
- Crée un fichier placeholder.png neutre dans le même 
  dossier pour les cas d'erreur de chargement
